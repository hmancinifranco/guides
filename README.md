## Uso

Cada carpeta contiene una guía autocontenida en formato HTML. Se publican automáticamente via GitHub Pages.

Para agregar una nueva guía:
1. Crear una carpeta con nombre descriptivo
2. Agregar un `index.html` dentro
3. Commitear y pushear a `main`
4. Estará disponible en `https://hmancinifranco.github.io/guides/<nombre-carpeta>/`
